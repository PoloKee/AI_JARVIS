# Jarvis AI — Elevator Pitch

Most AI assistants live in one box — a chat window and nothing else. Jarvis is built as a system instead: a monorepo that organizes a web app, an API, a desktop assistant, shared packages, infrastructure, and docs under one roof. That structure is deliberate — it is designed to scale toward real-time AI, skills and plugins, persistent memory, and orchestration across them all, with a desktop GUI in the mix. For a builder who wants an assistant that grows new abilities without being rebuilt every time, Jarvis is the foundation.

**Tagline:** One assistant, everywhere — web, API, and desktop in a single system.
